# Flipping Credit Card UI

A simple front-end UI project that simulates a flipping credit card effect using
pure HTML and CSS. The card flips on hover to show front and back sides.

## Features
- Card flip animation using CSS transform
- Front and back card design
- Smooth transition effects
- No JavaScript used

## Technologies Used
- HTML5
- CSS3 (Flexbox, Transforms, Transitions)

## Note
This project was built for learning and practice purposes.
